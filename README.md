# Lectures on Quantum Tensor Networks — project page

Buildless static project page for GitHub Pages.

## Files

- `index.html` — semantic page content and inline decorative network SVG
- `styles.css` — responsive visual system
- `script.js` — navigation and progressive reveal behavior
- `.nojekyll` — prevents Jekyll processing on GitHub Pages

## Preview

Serve this directory over HTTP, for example:

```sh
python3 -m http.server 4173
```

No package install or build step is required.

## Publication

The directory is suitable for the root of a `gh-pages` branch. The scientific
content is grounded in the manuscript headings at repository commit
`0c644b2b01dd9e0c9e24b151ae42e32dd18a9157`.
