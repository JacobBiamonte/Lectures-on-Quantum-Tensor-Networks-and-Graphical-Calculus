# Collected Works project instructions

This project is part of the Biamonte Collected Works campaign. Read `PROJECT-REGISTRY.md` before creating, cloning, renaming, copying, or linking any Overleaf project or GitHub repository. Verify identity from the exact Overleaf project ID and GitHub URL; never infer identity from a title. If the mapping is absent or ambiguous, stop and reconcile the registry before creating anything.

- Preserve a complete source-only snapshot before the first edit.
- Treat official, historical, arXiv, journal, thesis, publisher, and preserved Overleaf sources as immutable evidence.
- Make proposed scientific edits only in an authorized candidate. Keep all science `PENDING_JACOB` until Jacob accepts it.
- Use visible review markup for manuscript changes and preserve unresolved gates.
- Transfer only source files. Never upload or commit PDFs or generated build artifacts.
- Do not change collaborators, permissions, project identity, compiler settings, publication state, or access controls without exact authorization.
- Before any GitHub push, verify the private remote and intended files, run `git pull --ff-only` immediately before pushing, then verify `HEAD = upstream = remote` and a clean tree. Never force-push.
- Do not send correspondence, contact coauthors or editors, submit, publish, spend credits, or claim approval.

The accountable operational record is the existing Collected Works Imprint task linked in `PROJECT-REGISTRY.md`.
